# คู่มือติดตั้ง CivicHUD บน Windows — ทำตามทีละขั้น

คู่มือนี้เขียนสำหรับคนที่ไม่เคยลงโปรแกรมให้บอร์ด ESP32 มาก่อน ถ้าหน้าจอหรือเมนูของคุณไม่เหมือนชื่อที่เขียนไว้ ให้หยุดตรงนั้นก่อน อย่าลองเลือกบอร์ดหรือกดล้างข้อมูลแบบสุ่ม และขอให้คนที่คุ้นกับคอมพิวเตอร์ช่วยดู

> **สำคัญก่อนซื้อของหรือเสียบกับรถ:** โค้ดชุดนี้เคยทดสอบกับรถ Honda Civic FC 1.8 เพียงคันเดียว และอะแดปเตอร์ ELM327 ที่ใช้ Bluetooth แบบ Classic รุ่นที่ระบุว่า v1.5 หน้าจออาจเปิดได้กับบอร์ดเดียวกัน แต่ยังรับรองไม่ได้ว่าจะอ่านเลขระยะหรือข้อมูล ECU ของรถทุกรุ่นได้ ให้ตรวจปี รุ่นย่อย และตลาดของรถก่อนซื้ออุปกรณ์ โดยเฉพาะรถรุ่นเก่าหรือรถที่ใช้ระบบเฉพาะของผู้ผลิต

> **ข้อจำกัดข้อมูลตัวอย่าง:** เฟิร์มแวร์รุ่นปัจจุบันยังมีข้อมูลเริ่มต้นและประวัติตัวอย่างของ Civic FC 1.8 + LPG รวมถึงเลขไมล์ที่ไม่ใช่ของผู้ติดตั้ง หน้าเว็บตั้งค่าแก้เลขไมล์หน้าปัดและรอบบำรุงรักษาได้ แต่ยังแก้เลขไมล์ “ตอนเข้ารับบริการครั้งล่าสุด” หรือลบประวัติตัวอย่างไม่ได้ จึงยังไม่ควรใช้ข้อมูลเตือนบำรุงรักษาเป็นประวัติจริงของรถคันอื่น จนกว่าจะมีการปรับค่าเริ่มต้นของเฟิร์มแวร์สำหรับรถคันนั้น

## 1. เตรียมอุปกรณ์ก่อน

ให้ตรวจชื่อรุ่นบนประกาศขายหรือถามผู้ขายก่อนจ่ายเงิน

| ต้องมี | เลือกอย่างไร |
|---|---|
| บอร์ดจอ ESP32 | รุ่น **ESP32-2432S028R / CYD**, จอสี 2.8 นิ้ว 240×320, จอสัมผัสแบบกด (XPT2046), ชิป ESP32 รุ่นปกติที่รองรับ Bluetooth Classic |
| อะแดปเตอร์ OBD-II | แบบเสียบช่อง OBD ของรถ และสื่อสาร **Bluetooth Classic SPP**; ตัวอย่างที่เคยทดสอบระบุ ELM327 v1.5 ชื่อ Bluetooth “OBDII” และ PIN 1234 |
| สาย USB สำหรับบอร์ด | ต้องเป็น **สายส่งข้อมูล** ไม่ใช่สายชาร์จอย่างเดียว; เลือกหัว USB-C หรือ Micro-USB ให้ตรงกับช่องบนบอร์ดที่ซื้อ |
| คอมพิวเตอร์ Windows | ใช้ติดตั้งโปรแกรมและอัปโหลดเฟิร์มแวร์ |

**อย่าซื้อบอร์ดรุ่นใกล้เคียงโดยดูแค่คำว่า ESP32 หรือ CYD**: อย่าใช้ ESP32-C6, ESP32-S3, จอ 3.5 นิ้ว หรือบอร์ดที่ใช้ชิปจอ/ระบบสัมผัสคนละแบบ คู่มือนี้ตั้งค่าให้บอร์ด ESP32-2432S028R เท่านั้น

**อย่าซื้ออะแดปเตอร์ Bluetooth แบบ BLE-only หรือแบบ Wi-Fi** เพราะเฟิร์มแวร์ปัจจุบันใช้ Bluetooth Classic จาก ESP32 ไม่ได้ใช้ BLE การเขียนคำว่า ELM327 บนกล่องอย่างเดียวก็ยังไม่ยืนยันว่ารองรับทุกคำสั่งหรือรถทุกคัน อะแดปเตอร์เลียนแบบบางรุ่นคุณภาพไม่สม่ำเสมอ ควรเลือกร้านที่คืนสินค้าได้

โทรศัพท์ไม่ต้องเชื่อม Bluetooth กับอะแดปเตอร์ OBD: บอร์ด ESP32 จะเชื่อมกับอะแดปเตอร์ ส่วนโทรศัพท์ใช้ Wi-Fi เฉพาะตอนเปิดหน้าตั้งค่า

## 2. ติดตั้งโปรแกรมบน Windows

ใช้เฉพาะโปรแกรมเหล่านี้:

1. ติดตั้ง **Arduino IDE 2** จาก [หน้า Download ของ Arduino](https://www.arduino.cc/en/software) เลือกตัวติดตั้ง Windows แล้วเปิดไฟล์ที่ดาวน์โหลด ทำตามปุ่ม Next จนติดตั้งเสร็จ
2. ยังไม่ต้องติดตั้ง ESP-IDF, PlatformIO, Python หรือ Git เพื่อทำตามคู่มือนี้

เปิด Arduino IDE แล้วติดตั้งส่วนรองรับ ESP32:

1. เปิด **File > Preferences** (บางเครื่องอาจใช้ **File > Settings**)
2. หา **Additional boards manager URLs** แล้วเพิ่ม URL นี้:

   ~~~text
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ~~~

3. กด **OK** แล้วเปิด **Tools > Board > Boards Manager**
4. ค้นคำว่า **esp32** แล้วเลือกแพ็กเกจ **esp32 by Espressif Systems**
5. เลือกเวอร์ชัน **3.3.10** แล้วกด **Install** เวอร์ชันนี้ตรงกับสภาพแวดล้อมที่ใช้ build เฟิร์มแวร์ในโครงการ หากไม่มีเวอร์ชันนี้ให้เลือก ให้หยุดและแจ้งผู้ดูแลก่อนใช้เวอร์ชันอื่น
6. รอจนติดตั้งเสร็จ แล้วปิดและเปิด Arduino IDE ใหม่หนึ่งครั้ง

## 3. ติดตั้งไลบรารีที่เฟิร์มแวร์ใช้

ไลบรารีคือส่วนเสริมที่ช่วยให้โปรแกรมวาดจอและอ่านจอสัมผัสได้

1. เปิด **Sketch > Include Library > Manage Libraries**
2. ค้นหา **TFT_eSPI by Bodmer** เลือกเวอร์ชัน **2.5.43** แล้วกด **Install**
3. ค้นหา **XPT2046_Touchscreen by Paul Stoffregen** เลือกเวอร์ชัน **1.4** แล้วกด **Install**

อย่าติดตั้งไลบรารีที่ชื่อคล้ายกันจากผู้พัฒนาคนอื่น ถ้า Arduino IDE ถามว่าจะติดตั้ง dependency เพิ่มหรือไม่ ให้เลือกติดตั้งตามที่โปรแกรมแนะนำ

## 4. ตั้งค่าไลบรารีจอให้ตรงกับบอร์ด

ถ้าข้ามขั้นนี้ จออาจไม่แสดงภาพหรือภาพผิดสี แม้คอมไพล์ผ่านก็ตาม

1. ดาวน์โหลดไฟล์โครงการเป็น ZIP จาก [หน้า GitHub ของ CivicHUD](https://github.com/armkong33120/civic-hud) โดยกดปุ่ม **Code > Download ZIP**
2. คลิกขวาไฟล์ ZIP แล้วเลือก **Extract All…** เพื่อแตกไฟล์
3. ในโฟลเดอร์ที่แตกไฟล์แล้ว หาไฟล์:

   ~~~text
   hardware/Setup_CYD_ESP32_2432S028.h
   ~~~

4. เปิดโฟลเดอร์ไลบรารี TFT_eSPI ของ Windows โดยทั่วไปอยู่ที่:

   ~~~text
   Documents/Arduino/libraries/TFT_eSPI/
   ~~~

   ถ้าไม่พบ ให้เปิด Arduino IDE แล้วเลือก **Sketch > Show Sketch Folder** จากนั้นย้อนกลับไปที่โฟลเดอร์ Documents/Arduino/libraries
5. ในโฟลเดอร์ TFT_eSPI เปิดโฟลเดอร์ **User_Setups** ถ้ายังไม่มี ให้สร้างโฟลเดอร์ชื่อนี้
6. คัดลอกไฟล์ Setup_CYD_ESP32_2432S028.h จากข้อ 3 ไปไว้ใน User_Setups
7. เปิดไฟล์ **User_Setup_Select.h** ที่อยู่ในโฟลเดอร์ TFT_eSPI ด้วย Notepad
8. หาและใส่เครื่องหมาย // ด้านหน้า setup อื่นที่เปิดใช้อยู่ แล้วให้มีบรรทัดนี้เปิดใช้อยู่เพียงบรรทัดเดียว:

   ~~~cpp
   #include <User_Setups/Setup_CYD_ESP32_2432S028.h>
   ~~~

   ไฟล์นี้มักมีบรรทัดค่าเริ่มต้น #include <User_Setup.h> ให้ใส่ // ข้างหน้าเพื่อปิด เช่น //#include <User_Setup.h>
9. กด **File > Save** แล้วปิด Notepad

เก็บสำเนาไฟล์ Setup นี้ไว้อีกที่หนึ่งด้วย เพราะการอัปเดตไลบรารี TFT_eSPI อาจเปลี่ยนไฟล์เลือก setup ได้

## 5. เปิดโครงการ

1. ในโฟลเดอร์ที่แตกจาก ZIP เปิดไฟล์:

   ~~~text
   firmware/civic_hud/civic_hud.ino
   ~~~

   ให้เปิดไฟล์นี้จากในโฟลเดอร์ civic_hud โดยตรง
2. ถ้ามีหน้าต่างถามว่าจะย้ายหรือคัดลอกไฟล์ไปยังโฟลเดอร์ชื่อเดียวกับ sketch หรือไม่ ให้เลือกตัวเลือกที่ทำให้ civic_hud.ino อยู่ในโฟลเดอร์ civic_hud
3. รอให้ Arduino IDE ตรวจไลบรารี ถ้ามีข้อความว่าไม่พบ TFT_eSPI หรือ XPT2046_Touchscreen ให้กลับไปทำข้อ 3 และตรวจว่าติดตั้งในบัญชี Windows เดียวกัน

## 6. เลือกบอร์ดและค่าที่ถูกต้อง

ต่อบอร์ดเข้าคอมพิวเตอร์ด้วยสาย USB ส่งข้อมูล แล้วเลือกใน Arduino IDE:

1. เปิด **Tools > Board > esp32**
2. เลือก **ESP32-2432S028R** (ชื่อเต็มอาจแสดงต่างกันเล็กน้อย)
3. เลือกค่าต่อไปนี้ในเมนู **Tools**:

   | เมนู | ค่าที่ต้องเลือก |
   |---|---|
   | Partition Scheme | **Huge APP (3MB No OTA/1MB SPIFFS)** |
   | Upload Speed | **460800** |
   | Flash Size | **4MB** ถ้ามีให้เลือก |
   | CPU Frequency | **240MHz (WiFi/BT)** ถ้ามีให้เลือก |
   | Erase All Flash Before Sketch Upload | **Disabled / ปิด** |

การตั้งค่าที่โครงการใช้เรียกว่า FQBN คือ:

~~~text
esp32:esp32:jczn_2432s028r:PartitionScheme=huge_app,UploadSpeed=460800
~~~

**อย่ากด Erase All Flash / ล้าง Flash** หากบอร์ดนี้เคยใช้งานแล้ว เพราะอาจลบเลขไมล์ จุดอ้างอิง OBD และประวัติที่บันทึกอยู่ในบอร์ด การอัปโหลดโค้ดตามปกติไม่จำเป็นต้องสั่งล้างข้อมูล

## 7. ตรวจว่าโปรแกรมคอมไพล์ได้ก่อนอัปโหลด

1. กดปุ่มเครื่องหมายถูก **Verify** มุมซ้ายบน
2. รอจนจบ ถ้าด้านล่างขึ้น **Done compiling** หรือไม่มีข้อความ error สีแดง แปลว่าผ่านขั้นตรวจโค้ด ยังไม่ได้อัปโหลดลงบอร์ด
3. ถ้ามี error ให้จดข้อความ error ไว้ อย่าลบโฟลเดอร์หรือเปลี่ยนบอร์ดไปเรื่อย ๆ ตรวจเวอร์ชัน core, ไลบรารี และการตั้งค่า TFT_eSPI ก่อน

## 8. เลือกช่อง USB (COM Port)

COM Port คือชื่อช่องเชื่อมต่อ USB ของบอร์ดใน Windows:

1. ถอดสาย USB ออกจากบอร์ดก่อน แล้วเปิด **Device Manager** (คลิกขวาปุ่ม Start > Device Manager)
2. ขยายหัวข้อ **Ports (COM & LPT)**
3. เสียบสาย USB กลับ รอสักครู่ แล้วดูว่ามีรายการใหม่ เช่น **USB-SERIAL CH340 (COM5)** หรือ **Silicon Labs CP210x (COM6)** ปรากฏขึ้นหรือไม่
4. ใน Arduino IDE เปิด **Tools > Port** แล้วเลือก COM หมายเลขเดียวกับที่เพิ่งปรากฏ อย่าเลือก COM จากตัวอย่างในคู่มือนี้ เพราะหมายเลขแต่ละเครื่องไม่เหมือนกัน

ถ้าไม่เห็นช่อง COM:
- ลองสาย USB อีกเส้นที่ยืนยันแล้วว่าส่งข้อมูลได้ และลองช่อง USB อื่นของคอมพิวเตอร์
- ตรวจชื่อชิป USB-to-Serial บนบอร์ดหรือใน Device Manager แล้วลงเฉพาะไดรเวอร์จากผู้ผลิต: [WCH CH340/CH341](https://www.wch.cn/downloads/ch341ser_exe.html) หรือ [Silicon Labs CP210x](https://www.silabs.com/software-and-tools/usb-to-uart-bridge-vcp-drivers)
- บอร์ดแต่ละล็อตอาจใช้ชิปคนละรุ่น อย่าติดตั้งไดรเวอร์ทั้งสองตัวแบบเดาสุ่ม

## 9. อัปโหลดโปรแกรมลงบอร์ด

ก่อนกดอัปโหลด ให้ตรวจอีกครั้งว่าบอร์ดที่เลือกเป็น ESP32-2432S028R และ Port เป็น COM ของบอร์ดจริง

1. ปิด **Serial Monitor** ถ้าเปิดอยู่ เพราะอาจยึดช่อง COM ไว้
2. กดปุ่มลูกศร **Upload** มุมซ้ายบน
3. รอ Arduino IDE แสดง **Connecting…** และเริ่มเขียนข้อมูล อย่าถอดสายระหว่างนี้
4. ถ้าค้างที่ Connecting นานเกินไป ให้กดปุ่ม **BOOT** บนบอร์ดค้างไว้ตอนขึ้น Connecting และปล่อยเมื่อเริ่มเขียนข้อมูล หากบอร์ดไม่มีปุ่ม BOOT ให้หยุดก่อน อย่าลัดวงจรขาใด ๆ
5. เมื่อแสดง **Done uploading** ให้รอบอร์ดเริ่มใหม่ หน้าจอควรติดและแสดง CivicHUD

ถ้าอัปโหลดไม่สำเร็จ ให้ลด Upload Speed เป็น **115200** แล้วลองใหม่ ตรวจสายและ COM Port ก่อน หากยังไม่ผ่าน ให้จดข้อความ error และถ่ายรูปหน้าจอเพื่อขอความช่วยเหลือ

## 10. ต่อ OBD-II และตรวจการเชื่อมต่อ

1. จอดรถในที่ปลอดภัย ดึงเบรกมือ และอย่าทำขั้นตอนตั้งค่าขณะขับรถ
2. เสียบอะแดปเตอร์ OBD-II เข้าช่อง OBD ของรถ เปิดสวิตช์กุญแจตามที่ผู้ผลิตรถแนะนำ
3. บอร์ดตั้งชื่อและ PIN เริ่มต้นเป็น **OBDII / 1234**; โดยทั่วไปบอร์ดจะลองเชื่อมต่อเอง ไม่ต้องจับคู่ OBD กับโทรศัพท์ก่อน
4. สังเกตข้อความสถานะบนหน้าจอ บอร์ดที่แสดงว่าเชื่อม Bluetooth ได้ยังไม่ได้ยืนยันว่าอ่านข้อมูล ECU ของรถได้ หากรถ/อะแดปเตอร์ไม่รองรับข้อมูลที่โค้ดใช้ เลขระยะอาจไม่เพิ่มหรืออาจคลาดเคลื่อน
5. การทดสอบบนถนนให้ทำโดยผู้ขับที่มีสมาธิกับถนน ห้ามดูหรือแตะหน้าจอระหว่างขับ

ถ้าอะแดปเตอร์ใช้ชื่อหรือ PIN ไม่ตรงค่าเริ่มต้น ต้องเปลี่ยนค่าผ่านหน้าตั้งค่าในหัวข้อถัดไป

## 11. ตั้งเลขไมล์และ Wi-Fi ตั้งค่า

เฟิร์มแวร์รุ่นนี้กำหนดจุดเริ่มต้นไว้ที่ **98,540 km** ซึ่งเป็นค่าตัวอย่างจากโครงการ ให้ตรวจเลขไมล์จริงบนหน้าปัดรถก่อนใช้งาน

1. ให้รถจอดนิ่งสนิท
2. แตะบริเวณกลางแถบล่างของหน้าจอเพื่อเปิดหน้า CPU/RAM
3. แตะปุ่ม Wi-Fi ตั้งค่า แล้วรอให้บอร์ดเปิดเครือข่ายชื่อ **CivicHUD**
4. จากโทรศัพท์ เชื่อมต่อ Wi-Fi ชื่อ CivicHUD เครือข่ายนี้ปัจจุบัน **ไม่มีรหัสผ่าน** และใช้สำหรับตั้งค่าใกล้ตัวบอร์ดเท่านั้น
5. เปิดเบราว์เซอร์ พิมพ์ **http://192.168.1.1**
6. กรอกเลขไมล์ที่อ่านจากหน้าปัดจริง ตรวจค่าให้ถูก แล้วกดบันทึก
7. ถ้าชื่อ Bluetooth หรือ PIN ของอะแดปเตอร์ไม่ใช่ OBDII / 1234 ให้แก้ในหน้านี้ด้วย
8. ตั้งรอบบำรุงรักษาและรายการที่ต้องการให้แสดง จากนั้นกดบันทึก
9. เมื่อเสร็จ ให้ปิดหน้า Wi-Fi ตั้งค่าบนบอร์ด และตัดการเชื่อมต่อ Wi-Fi CivicHUD จากโทรศัพท์

เครือข่าย CivicHUD ไม่มีรหัสผ่านและหน้าเว็บไม่มีระบบล็อกอิน อย่าเปิด Wi-Fi ตั้งค่าขณะขับรถหรือในที่สาธารณะที่มีคนอื่นอยู่ใกล้ เพราะคนที่เชื่อมเครือข่ายนี้ได้อาจเปลี่ยนค่าที่บอร์ดบันทึกไว้ได้

**การตั้งเลขไมล์หน้าปัดไม่ทำให้ PID 01 31 กลายเป็นเลขไมล์สะสมของรถ**: ค่านี้หมายถึงระยะตั้งแต่ล้างรหัสปัญหาเครื่องยนต์ครั้งล่าสุด โครงการนำมาคำนวณร่วมกับจุดอ้างอิง และอาจรีเซ็ตได้เมื่อมีการลบรหัส จึงไม่ใช่เครื่องวัดระยะทางที่รับรองความแม่นยำ

## แก้ปัญหาเบื้องต้น

| อาการ | ให้ลองตรวจ |
|---|---|
| Arduino IDE แจ้งไม่พบ ESP32-2432S028R | ตรวจว่าติดตั้ง esp32 by Espressif Systems เวอร์ชัน 3.3.10 และเปิด IDE ใหม่แล้ว |
| ขึ้น TFT_eSPI error หรือจอมืด | ตรวจเวอร์ชัน TFT_eSPI และบรรทัดใน User_Setup_Select.h ว่าเลือก Setup_CYD_ESP32_2432S028.h เพียงชุดเดียว |
| ไม่เห็น COM Port | ลองสายข้อมูลเส้นอื่น ตรวจ Device Manager และลงไดรเวอร์ให้ตรงชิป USB-to-Serial |
| ค้างที่ Connecting… | ปิด Serial Monitor ตรวจ COM Port แล้วลอง BOOT ตามข้อ 9; หากยังไม่ได้ให้ลด Upload Speed |
| หน้าจอติดแต่ไม่เชื่อมรถ | ตรวจว่าอะแดปเตอร์เป็น Bluetooth Classic ไม่ใช่ BLE-only, เสียบแน่น, เปิดกุญแจ และชื่อ/PIN ตรงกับการตั้งค่า |
| บอร์ดเชื่อมอะแดปเตอร์แล้วแต่เลขไมล์ไม่เปลี่ยน | รถคันนั้นอาจไม่รองรับ PID/โปรโตคอลที่ใช้ หรือ PID31 อาจไม่พร้อม อย่าสรุปว่าระยะที่แสดงถูกต้องจากสถานะ Bluetooth อย่างเดียว |

## ขอบเขตที่ควรรู้ก่อนให้ผู้อื่นใช้

- ฮาร์ดแวร์และเฟิร์มแวร์ในคู่มือนี้เป็นรุ่นที่ใช้ในโครงการ ไม่ใช่ชุดติดตั้งสากลสำหรับ ESP32 ทุกแบบ
- ทดสอบกับ Civic FC 1.8 หนึ่งคันเท่านั้น รถรุ่นอื่นต้องตรวจ OBD-II protocol, Bluetooth Classic และ PID ที่ ECU รองรับก่อน
- มีค่าเริ่มต้น/ประวัติตัวอย่างเฉพาะ Civic FC 1.8 + LPG; ผู้ติดตั้งต้องไม่ถือว่าข้อมูลตัวอย่างเป็นประวัติจริงของตน
- ถอดอะแดปเตอร์ OBD-II เมื่อไม่ใช้เป็นเวลานาน เพราะอะแดปเตอร์บางรุ่นอาจกินไฟจากแบตเตอรี่รถขณะจอด
- หากแก้เลขไมล์หรือข้อมูลในบอร์ดที่เคยใช้แล้ว อย่าล้าง Flash เอง เพราะอาจลบข้อมูลระยะและประวัติที่บันทึกอยู่
